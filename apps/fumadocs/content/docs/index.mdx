Full Stack Template is a starting point for building web and mobile applications with a shared API, authentication, and database.

## Install Dependencies

Clone the repository and install dependencies from the project root:

```bash
git clone https://github.com/4anklee/full-stack-template.git
cd full-stack-template
bun install
```

Use the Bun version specified in the root `package.json`.

## Configure Your Environment

Create local `.env` files in `apps/web`, `apps/server`, and `apps/native`, using each app's `.env.schema` as a reference.

Configure the server's database connection, authentication secret, allowed origin, and billing credentials. Set the web and native server URLs to your API address. Environment files stay out of version control.

Apply the database schema once the connection is configured:

```bash
bun run db:push
```

## Start Development

```bash
bun run dev
```

The web app runs at `http://localhost:3001`, the API at `http://localhost:3000`, and these docs at `http://localhost:4000`. Open the native app through its Expo development server.

Continue to [Development](/docs/development) for the project structure and common commands.
